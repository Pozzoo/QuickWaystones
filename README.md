# QuickWaystones v2.3.0
QuickWaystones is a Minecraft plugin that brings the convenience of instant travel to your worlds with the introduction of waystones. Seamlessly teleport between locations and enhance your gameplay experience.

### ⚙️ **Customizable Settings**
- Toggle the use of waystone passes to suit your server’s needs using `/quickwaystones setEnableWaystonePass`.
- Enable or disable global waystone access with `/quickwaystones setHideUndiscoveredWaystones`.
- Set a teleport cost with `/quickwaystones setXpCost <amount>`! (or disable it by setting to 0)
- Config updates are migrated automatically between versions.
- QuickWaystones checks for newer releases and can notify you when an update is available.
